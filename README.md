## Sobre

O **NTE Launcher PT-BR** é um launcher desktop desenvolvido e projetado para facilitar a instalação da tradução não-oficial PT-BR do jogo **Neverness to Everness**.

### Principais Funcionalidades

- **Detecção automática** do diretório do jogo
- **Download e instalação automática** dos arquivos de tradução
- **Atualização em um clique** sempre que uma nova versão da tradução é lançada
- **Remoção segura** dos arquivos da tradução do jogo

## Desenvolvimento

### Pré-requisitos

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.11.5 ou superior)
- [Dart SDK](https://dart.dev/get-dart)
- Windows 10/11 com Visual Studio e workload "Desktop development with C++"

### Instalando dependências

```bash
flutter pub get
```

### Build para Windows

```bash
flutter build windows --release
```

---

## Aviso Importante

⚠️ **A Tradução PT-BR NTE é um mod não oficial.** Embora o risco seja considerado baixo, o uso de qualquer modificação pode resultar em **penalidades ou banimento da conta**. Utilize por sua conta e risco.

Este launcher é uma ferramenta de conveniência e não modifica os arquivos do jogo além dos necessários para a tradução. No entanto, a política oficial do jogo pode mudar a qualquer momento.
